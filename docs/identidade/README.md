# SARGTECH — Identidade Visual v0.1

Proposta inicial para uso no Gestão Inteligente e futura landing page da marca.

## Conceito
Estrutura + sinal + precisão. O símbolo modular sugere um fluxo em “S” e um ponto central de decisão/dado. A marca deve parecer uma empresa de tecnologia aplicada a negócios: moderna, séria e confiável, sem clichês de robô/cérebro/circuitos.

## Diferenciação da SargLab
A SargLab usa azul-petróleo, creme e laranja. A SARGTECH v0.1 usa Midnight + Cobalt/Indigo + neutros frios. Não reutilizar a paleta da SargLab como identidade corporativa.

## Arquivos
- logos/*.svg: preferidos para web.
- logos/*.png: uso rápido em documentos/apresentações.
- tokens/sargtech-tokens.css: variáveis CSS para landing page e produto.
- tokens/sargtech-tokens.json: tokens portáveis para design/dev.

## Tipografia
Usar Inter ou Manrope por referência; não há arquivos de fonte neste pacote. Em produção, usar fonte licenciada/servida pela própria aplicação ou fallback de sistema.

## Status
Identidade v0.1 — pronta para protótipo e implementação do update, mas deve ser aprovada visualmente antes de ser tratada como marca definitiva.
